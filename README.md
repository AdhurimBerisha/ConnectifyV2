# Installation
1.Clone the repository
git clone https://github.com/AdhurimBerisha/ConnectifyV2.git

2.In the backend directory, create a ".env" file and set the following variable:
MONGO_URI=<your_mongodb_uri>
Set the parameters for the MySQL Database
'host': 'your_mysql_host',
'user': 'your_mysql_user',
'password': 'your_mysql_password',
'database': 'your_mysql_database',

3.Start the server side
cd backend
npm install
npm start

4.Start the client side
cd client
npm install
npm start
